# 戳戳樂（Stamppad）

夜市戳洞兌獎遊戲：一張戳板上每一格都藏著結果（獎品／再戳一次／銘謝惠顧）。付一枚「代幣」戳開格子看結果，收集到目標數量的獎品即完成一輪。

## 玩法

1. 一張 6×5＝30 格的戳板，每格背後藏一樣結果。
2. 點一格，付 1 枚代幣戳開，看到結果：
   - **🍭🍬🧸 獎品**：收集起來。
   - **↻ 再戳一次**：退回 1 枚代幣。
   - **謝 銘謝惠顧**：什麼都沒有。
3. 集滿 6 個獎品就完成這一輪。
4. 代幣用完且沒有再戳機會時，換一張戳板重新開始。

## 操作

- **滑鼠／觸控**：點未開的格子戳開。
- **換一張戳板**：重新生成一局（重置收集進度與代幣）。
- 聲音開關在右上角（戳開／再戳 ogg ＋ Web Audio 合成音效，見 `assets/sfx/`）。

## 技術

- `game.js`：純函式邏輯（獎池分配、戳開判定、代幣管理、目標收集、勝負邊界）。
- `app.js`：DOM 渲染、戳開互動、統計、狀態提示。
- `audio.js`：Kenney UI Audio（ogg）＋ Web Audio 合成音效。
- 本作以本機遊玩為主；無 KV 最高分（單輪目標固定）。
